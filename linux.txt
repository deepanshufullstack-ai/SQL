Pipe Operator
pipe operator makes output of the first command and make that output as an input for the second or another command
1) ls -lh | sort -> perform sorting on the list in alphabetic or non alphabetic order
2) ls -lh | sort -k5h -> perfom sorting on the list based on the key column number
3) cat foods.txt | grep "pizza" -> return foods.txt content and perform searching on the foods.txt content for pizza
4) ls -lh | sort -k5h | tail -5 -> first return list then sort that list using column 5 and return the last 5 files only

Grep Command
the grep command is used to search anything in the file and the pattern in the grep command is case sensitive
1) grep "happiness" hello.txt -> search happiness in the hello.txt file
2) grep happiness hello.txt
3) grep -i "life" hello.txt -> return all the content of hello.txt file where life is exist
4) grep -ic "life" hello.txt -> return the count of life in the hello.txt file
5) grep -in "life" hello.txt -> return the searching content with line number
6) grep -iw "life" hello.txt -> search specific word in the file
7) grep -iB2 "tomato" foods.txt -> return search content with 2 line in above
8) grep -iA2 "tomato" foods.txt -> return search content with 2 line in below
9) grep -iB2 -A2 "tomato" foods.txt -> return search content with 2 line above and 2 line below
10) grep -iC2 "tomato" foods.txt -> return search content with 2 line above and 2 line below
11) grep -r "imp" -> search imp recursively in each file on the directory 
12) grep -r "imp" Documents/ -> search imp in the each file of the Documents directory
13) grep "^In" -iw sample -> seacrh pattern in the file from start of the line
14) grep "sky" sample meditations -> search sky in both file and return the search content
